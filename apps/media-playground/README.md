## Stack

- Next
- Tailwind
- Shadcn/ui
- React
- Typescript

## Getting Started

Run Dev Server (next dev + turbo)
```bash
yarn dev:eden
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Cost Estimate Calculations

This uses expressions delivered by modal api in formats like `cost_estimate: (width * height / 1024) * n_samples`

These expressions are evaluated using [expr-eval](https://github.com/silentmatt/expr-eval).
