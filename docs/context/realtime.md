# Realtime Voice Conversations

This document describes the `/realtime` route implementation for real-time voice conversations with Eden agents using ElevenLabs Conversational AI.

## Overview

The realtime feature enables live voice conversations between users and Eden agents. It uses ElevenLabs' Conversational AI platform for speech-to-text, LLM processing, and text-to-speech, while integrating with Eden's agent system for persona, memory, and session management.

**Route**: `/realtime/[agentId]`

## Architecture Flow

```
User (Microphone)
    ↓
Frontend (media-playground)
    ↓ WebSocket/WebRTC
ElevenLabs Conversational AI
    ↓ (uses dynamic variables for injecting eden agent context into system prompt)
Eden Session (stores messages passively after they are generated by Elevenlabs API)
```

## Configuration Options

### 1. ElevenLabs Agent Configuration

The ElevenLabs Agent ID is hardcoded in `lib/voice/realtime-defaults.ts` as `ELEVENLABS_AGENT_ID` and is not configurable per-agent. All other settings are configurable per-agent.

Default values are defined in `lib/voice/realtime-defaults.ts`:

```typescript
interface RealtimeSettings {
  agent: string
  voice_id?: string | null
  language: string
  first_message?: string | null
  llm_model: RealtimeLLM
  temperature: number
  max_tokens: number
  tts_stability: number
  tts_speed: number
  tts_similarity_boost: number
}
```

#### Default Values

```typescript
DEFAULT_REALTIME_SETTINGS = {
  agent: '',
  voice_id: null,
  first_message: null,
  language: 'en',
  llm_model: 'claude-haiku-4-5',
  temperature: 0.8,
  max_tokens: 4096,
  tts_stability: 0.5,
  tts_speed: 1.0,
  tts_similarity_boost: 0.3,
}
```

### 2. LLM Options

Available LLM models (type `RealtimeLLM`):
- `gpt-5-mini`
- `gpt-5-nano`
- `gemini-2.5-flash`
- `claude-sonnet-4-5`
- `claude-haiku-4-5`

### 3. TTS Configuration

**Important:** The database and API use snake_case (`voice_id`, `tts_similarity_boost`), but when passing overrides to the ElevenLabs SDK's `startSession`, properties must use camelCase (`voiceId`, `similarityBoost`). This conversion happens in `use-voice-conversation.tsx`.

```typescript
// Database/API (snake_case)
interface RealtimeSettings {
  voice_id?: string
  tts_stability?: number
  tts_speed?: number
  tts_similarity_boost?: number
}

// ElevenLabs SDK overrides (camelCase)
interface TTSConfig {
  voiceId?: string         // ElevenLabs voice ID
  stability?: number       // 0.0 to 1.0 (lower = more expressive)
  speed?: number           // 0.7 to 1.2
  similarityBoost?: number // 0.0 to 1.0
}
```

### 4. User Input Fields

User input fields are configurable per-agent via the RealtimeTab UI:

```typescript
interface RealtimeSettings {
  // ... other settings
  user_input_fields?: string[]  // e.g., ['Name', 'Email', 'Company']
}
```

These fields are:
- Configured in the agent's Realtime settings tab
- Required in production mode (all fields must be non-empty to start)
- Optional in dev mode (`?dev=true`)
- Saved to Eden session as first message
- Used to personalize first message greeting
- All fields are free-text inputs (no type enforcement)

## Dynamic Variables System

ElevenLabs agents use dynamic variables (recommended over overrides) to inject runtime data:

### Variables Sent to ElevenLabs

```typescript
interface DynamicVariables {
  agent_system_prompt: string  // Complete system prompt
  first_message: string        // Personalized greeting
}
```

### System Prompt Construction

The `agent_system_prompt` is built from:

```markdown
You are {agent.name}.

## Description
{agent.description}

## Persona
{agent.persona}

## User Memory
{userMemory from memory-context API}

## Collective Knowledge
{collectiveMemory shards from memory-context API}
```

### First Message Personalization

If user provides name: `"Heey {userName}! {baseFirstMessage}"`

## Session Management

### Session Creation

When conversation starts:
1. Frontend calls `/api/realtime/session/create`
2. Creates Eden session with `agent_ids: [agentId]`
3. If user info provided, saves as first passive message
4. Session ID stored in `sessionIdRef`

### Message Logging

During conversation:
- Both user and agent messages are saved via `/api/realtime/session/message`
- Messages are "passive" - they don't trigger agent responses (handled by ElevenLabs)
- Uses Fastify endpoint: `POST /v2/sessions/add-message`

## AgentRealtime Settings Model

A separate `AgentRealtime` collection stores per-agent realtime configuration:

```typescript
// apps/api/src/models/AgentRealtime.ts
interface AgentRealtimeSchema {
  agent: ObjectId               // Reference to agent (unique index)
  voice_id?: string             // ElevenLabs voice ID
  language?: string             // e.g., 'en', 'nl' (default: 'en')
  first_message?: string        // Custom greeting message
  llm_model?: RealtimeLLM       // LLM selection (default: 'claude-haiku-4-5')
  temperature?: number          // 0-1 (default: 0.8)
  max_tokens?: number           // 1024, 2048, or 4096 (default: 4096)
  tts_stability?: number        // 0-1 (default: 0.5)
  tts_speed?: number            // 0-1.2 (default: 1.0)
  tts_similarity_boost?: number // 0-1 (default: 0.3)
  user_input_fields?: string[]  // User input field labels (default: [])
}
```

## Voice Options

Voices are fetched dynamically from the ElevenLabs v2 API at `/api/realtime/voices`. This ensures the voice list is always up-to-date with all voices available in your ElevenLabs account, including custom/cloned voices.

### API Endpoint

The `/api/realtime/voices` endpoint:
1. Fetches voices from `https://api.elevenlabs.io/v2/voices` (up to 100 voices)
2. Extracts metadata from the response
3. Applies client-side filtering based on query parameters
4. Returns filtered and sorted voices

**Query Parameters:**
- `gender`: Filter by gender ('male' or 'female') - extracted from `labels.gender`
- `language`: Filter by language code (e.g., 'en', 'nl') - extracted from `verified_languages[0].language` or `labels.language`

**Response:**
```typescript
{
  voices: VoiceOption[]
  hasMore: boolean
  totalCount: number  // Total unfiltered count from ElevenLabs
}
```

### Voice Metadata

Each voice includes:
- `value`: ElevenLabs voice ID
- `label`: Display name
- `description`: Combined labels (accent, age, gender, etc.)
- `category`: Voice category (generated, cloned, premade, professional, famous, high_quality)
- `previewUrl`: URL to preview the voice (optional)
- `gender`: Extracted from labels
- `language`: Primary language from verified_languages or labels
- `isOwner`: Whether the current user owns this voice

### UI Filters

The RealtimeTab provides two filter options:
1. **Gender filter**: Dropdown to filter by "All", "Male", or "Female"
2. **Match language**: Checkbox to filter voices matching the configured conversation language

When filters are active, the UI displays "{filtered count} of {total count} voices".

Users can also enter a custom voice ID if their voice isn't in the list.

## Implementation Notes

### Microphone Access
Uses specific constraints to prevent Android telephony mode:
```typescript
{
  echoCancellation: false,
  noiseSuppression: false,
  autoGainControl: false,
  channelCount: 1,
  sampleRate: 48000,
  sampleSize: 16,
}
```

### Volume Monitoring
Real-time microphone input volume displayed using Web Audio API:
- Creates AudioContext + AnalyserNode
- Uses RMS calculation on time-domain data
- Updates via requestAnimationFrame

### Connection States
```typescript
type ConnectionStatus =
  | 'disconnected'
  | 'connecting'
  | 'connected'
  | 'disconnecting'
  | 'error'
```
